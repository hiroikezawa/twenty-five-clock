# TWENTY-FIVE 配布版

Waveshare ESP32-S3-Touch-AMOLED-1.75 **Cなし・16MB** 専用。

25種類すべて12時間式の文字盤、毎正時の日付シャッフル、起動時・定期NTP同期、RTC補正、重力による回転、タッチ操作、時間帯別輝度、焼き付き対策を搭載。

## インストール

Assetsの **clock-25faces-non-c-16mb.zip** をダウンロードして展開します。Source code (zip) はビルド済みファームウェアではありません。

ESP-IDFは不要です。Python 3.10以降を用意し、展開先のREADMEに従ってesptoolをインストールして `flash.py --port COM3` を実行します。COM番号は環境に合わせて変更してください。更新時にNVSのWi-Fi設定・輝度は消去しません。

## 初回Wi-Fi設定

1. スマートフォン/PCを、時計画面の **Clock-175-XXXX** に接続。
2. パスワードは時計画面の **上段6文字＋下段6文字**、計12文字を続けて入力。
3. 「インターネットなし」でも接続を維持して **http://192.168.4.1/** を開く。
4. 設定ページで **自宅の2.4GHz Wi-Fi** と **自宅Wi-Fiのパスワード** を保存。
5. 再起動後にNTP同期。スマートフォン/PCは自宅Wi-Fiへ戻す。

`192.168.4.1` は自宅ルーターではなく、時計の設定APへ接続している間だけ開くページです。詳細・トラブル対応・文字盤一覧は同梱READMEに記載しています。
