# 検証記録

## 対象

Waveshare ESP32-S3-Touch-AMOLED-1.75（Cなし）、16MB Flash、8MB Octal PSRAM、ESP-IDF v5.5.5。2026-10-09に実機で検証した25文字盤版のアプリSHA-256：

`c9ae22c13ca12bf193066040383227b72d01b95641ade6053231f161cee7ca18`

## 実機で確認済み

- ESP-IDFビルド成功、COM3への書き込み・書き込みHash照合・通常起動。
- CO5300、CST9217（0x9217 / 466×466）、AXP2101、QMI8658加速度取得、Flash16MB、PSRAM8MB。
- USBからsystem timeとRTCを設定し、リセット後のJST復元。
- 保存した自宅Wi-Fiへの接続、IP取得、起動時NTP同期、RTC書き込み成功。
- 37度回転した25文字盤×120フレーム＝3,000フレームで描画＋QSPI転送がすべて16,667µs以内。最大13,038µs、Face別平均3,640〜11,260µs。個別数値は [benchmark-25.json](benchmark-25.json)。

測定はQSPI 40MHz、時分針を10:09付近で離し、秒を全周へ進める条件です。背景生成・角度変更・Wi-Fi通信・タッチ処理はこの測定に含めていません。診断後はSELF_TESTをOFFに戻した通常版を使用しています。

## ホスト検証

製品と同じCソースをDLL化し、Pythonから検証しました。

- 2000〜2099年36,525日：日付からの再現性、1日24種類の非重複、日付境界の非重複、任意の25日窓で全Face各24回の均等性。
- 全25Faceの10:09と22:09で針位置が一致。全て12時間式。
- 回転なし9,000フレーム、5角度で回転あり45,000フレーム：dirty tile復元と完全再描画がピクセル単位で一致。
- タップ・ダブルタップ・長押し・左右スワイプ・移動時の長押し抑止。
- 実際のC描画コードで25Faceのプレビューを生成。

## 未確認・制約

物理的な傾け方向、パネル発色、タッチ感度、長期間の連続稼働は、ホストテストとシリアルログによる確認とは区別してください。重力のない平置き方向は判定できません。RTCバックアップ電源なしで完全に電源を断つと時刻を保持できず、再投入後のNTP同期が必要です。

この記録は上記SHA-256のアプリを試験した結果であり、将来のビルドを自動的に実機検証済みとするものではありません。個人のSSIDや機器情報を含む元のシリアルログは配布物に含めません。

## 配布ツール

`python tools/package_release.py` と `python tests/test_release.py` で配布ZIPを生成・検証します。ハッシュ一致、破損バイナリ拒否、NVS向けの誤ったoffset拒否、32MB設定拒否、書き込みコマンドの3領域限定を検証します。これらはUSBを操作しません。
